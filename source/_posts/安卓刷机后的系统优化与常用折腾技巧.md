刷完第三方 ROM 后，很多设置都恢复默认了。这篇帮你把系统调教成顺手的形态。

## 安装必要的框架与应用

```bash
# 通过 ADB 安装 Magisk 管理器
adb install Magisk-v*.apk

# 安装 LSPosed 框架（需要先安装 Zygisk）
adb install LSPosed.apk
```

LSPosed 配合各种模块可以给系统注入强大的功能。

## 常用 ADB 优化命令

```bash
# 关闭系统动画，让界面更跟手（可保留）
adb shell settings put global window_animation_scale 0.5
adb shell settings put global transition_animation_scale 0.5
adb shell settings put global animator_duration_scale 0.5

# 显示所有应用通知
adb shell settings put global heads_up_notifications_enabled 1

# 关闭电池优化（对特定应用）
adb shell dumpsys deviceidle whitelist +com.example.app
```

## 备份与恢复

刷机后建议第一时间做完整备份：

```bash
# 备份应用与数据（需要 Root）
adb shell su -c "tar -cvf /sdcard/data_backup.tar /data/data/com.example.app"

# 使用 Titantium Backup / Swift Backup 批量备份
adb backup -apk -shared -all -f backup.ab
```

## 系统精简

用 Root 权限可以卸载系统内置应用（谨慎操作）：

```bash
adb shell su -c "pm uninstall --user 0 com.android.chrome"
adb shell su -c "pm disable-user --user 0 com.google.android.youtube"

# 查看可精简应用列表
adb shell pm list packages -s
```

## 内核调校

如果刷了支持的内核，可以调整调度策略：

```bash
# 查看可用调度器
adb shell su -c "cat /sys/block/mmcblk0/queue/scheduler"

# 切换到更适合日常使用的调度器
adb shell su -c "echo cfq > /sys/block/mmcblk0/queue/scheduler"
```

> 内核参数每个设备不同，改动前务必先记录原始值，防止设备变卡或异常。

## 小结

折腾到这一步，你的手机已经由你完全掌控了。记住一句话：**改动有风险，备份第一条**。
