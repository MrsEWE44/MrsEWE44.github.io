# 安卓设备禁用单个应用联网教程
1、需要root权限，无论你是在手机上用mt文件管理器还是连接电脑使用root shell都可以。
2、命令如下
2-1、禁用应用联网
```
iptables -I OUTPUT -m owner --uid-owner 软件的uid -j DROP
```

2-2、启用应用联网
```
iptables -I OUTPUT -m owner --uid-owner 软件的uid -j ACCEPT
```

这样可以通过命令管理应用的联网权限。
