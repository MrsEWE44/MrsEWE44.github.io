# 安卓10以上设备禁用摇一摇广告传感器教程

1、需要adb权限，无论你是在手机上用shizuku还是连接电脑使用adb shell都可以。
2、传感器命令如下
2-1、禁用某个应用的传感器权限
```
cmd sensorservice set-uid-state 软件包名 idle --user 0
```
2-2、启用某个应用的传感器权限
```
cmd sensorservice set-uid-state 软件包名 active --user 0
```

这样可以有效解决安卓10以上设备的摇一摇广告触发。
